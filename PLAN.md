# Lantern Keeper — Plan

A browser arcade survival game (Vampire Survivors–style). You play a human wanderer with a lantern in a dark forest; zombies shamble out of the dark to attack you, and you fight back to survive.

**Tech:** HTML5 Canvas + vanilla JS (ES modules), hosted on GitHub Pages, linted in GitHub Actions.

## Phase 1 — Playable core
- [x] M1. Repo setup: README, PLAN.md, blank canvas page, Pages deploy + lint CI
- [x] M2. The wanderer: move with WASD/arrows/touch, dark forest background, lantern light radius
- [x] M3. Zombies spawn from the darkness and chase you; health + game over
- [ ] M4. Auto-attack that kills zombies; score + survival timer

## Phase 2 — Progression
- [ ] M5. Zombies drop glow orbs → XP bar
- [ ] M6. Level-up screen: pick 1 of 3 upgrades (~6 upgrades)
- [ ] M7. Difficulty ramps over time + 2–3 new zombie types (runner, brute, …)

## Phase 3 — Polish
- [ ] M8. Title screen, pause, restart, saved high score
- [ ] M9. Particles, screen shake, sound effects
- [ ] M10. Balance pass, mobile controls polish, final README with play link
