# 🏮 Lantern Keeper

A browser arcade survival game. You're a lone wanderer lost in a dark forest at night, armed only with a lantern. Shadow creatures close in from the dark — your lantern's light burns them away. Survive, collect glow, level up, and see how long you last.

Built with plain HTML5 Canvas + JavaScript. No install, no build step.
